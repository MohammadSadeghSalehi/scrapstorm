# Scrapstorm League assets

Meshes, PBR textures, HDRIs, audio, UI stills, and cutscene video for
[MohammadSadeghSalehi/scrapstorm](https://github.com/MohammadSadeghSalehi/scrapstorm).

This is **data**, not the game. Clone the GitHub repo, then:

```bash
pip install -U huggingface_hub
node scripts/fetch-assets.mjs
```

Licenses are mixed (MIT originals, CC0 Poly Haven / Kenney, CC BY AmaraSpatial-10K).
See `SOURCES.md` and the game's `NOTICE` file.

Do not use these files as a generic asset dump without the game's attribution.
